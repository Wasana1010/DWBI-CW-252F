**1. Define Business Requirements**



The main objective of the OLAP cube is to support multidimensional

analysis of Sri Lankan G.C.E. Advanced Level Biological Science

examination data. The cube is designed to provide a clear view of

student performance from different perspectives such as student

demographics, examination information, and subject combinations.



The main analytical requirements are:



• Analyze student performance using Z-scores.

• Compare average Z-scores between male and female students.

• Analyze student performance according to birth year.

• Compare performance across different subject combinations.

• Determine the number of students belonging to different groups.

• Analyze Common General Test (CGT) performance.

• Support multidimensional analysis using different combinations

&#x20; of student, examination, and subject information.

• Support OLAP operations such as Slice, Dice, Roll-up,

&#x20; Drill-down, and Pivot.





**2. Identify the Data Source**



The data source selected for the OLAP implementation is the

"biological\_science\_high\_zscore\_new\_syllabus\_students.csv" dataset.



The dataset contains 11,715 student records with 19 original

attributes. It represents G.C.E. Advanced Level students from the

Biological Science stream following the new syllabus.



The dataset contains information related to:



• Student gender

• Student birth date

• Examination year

• Stream

• Syllabus

• Subject combinations

• Subject grades

• Z-score

• District rank

• Island rank

• Common General Test (CGT) result

• General English result



The CSV dataset was loaded into Google Colab and processed using

Python and the Pandas library. The cleaned data was then organized

into a star schema consisting of one fact table and three dimension

tables.



The resulting tables are:



• FACT\_RESULTS

• DIM\_STUDENT

• DIM\_EXAM

• DIM\_SUBJECT





**3. Define Dimensions and Hierarchies**



Three main dimensions were identified for the OLAP cube: Student,

Exam, and Subject. These dimensions provide different perspectives

for analyzing student examination performance.



3.1 Student Dimension



The Student Dimension contains information related to individual

students.



Attributes:

• Student Key

• Gender

• Birth Day

• Birth Month

• Birth Year



Hierarchy:

Birth Year → Birth Month → Birth Day → Student



This hierarchy allows the analysis to move from summarized birth-year

information to more detailed student-level information.



3.2 Exam Dimension



The Exam Dimension contains information related to the A/L examination.



Attributes:

• Exam Key

• A/L Year

• Stream

• Syllabus



Hierarchy:

A/L Year → Stream → Syllabus



This dimension allows examination results to be viewed according to

the examination year, stream, and syllabus.



3.3 Subject Dimension



The Subject Dimension represents the subject combinations followed

by students.



Attributes:

• Subject Key

• Subject 1

• Subject 2

• Subject 3



The subject dimension can be used to compare student performance

between different subject combinations.



The main dimensional structure of the cube can therefore be

summarized as:



Student Dimension:

Birth Year → Birth Month → Birth Day → Student



Exam Dimension:

A/L Year → Stream → Syllabus



Subject Dimension:

Subject Combination → Individual Subjects





**4. Choose Facts and Measures**



The central fact selected for the OLAP cube is the Student Examination

Result. Each record in the FACT\_RESULTS table represents the

examination performance of a student.



The fact table is connected to the dimensions through the following

foreign keys:



• student\_key – connects FACT\_RESULTS to DIM\_STUDENT

• exam\_key – connects FACT\_RESULTS to DIM\_EXAM

• subject\_key – connects FACT\_RESULTS to DIM\_SUBJECT



The main measures selected for multidimensional analysis are:



Student Count

This measure represents the number of students in a selected group.

The COUNT aggregation is used.



Z-Score

The Z-score is the primary measure used to analyze student examination

performance. Average, minimum, and maximum aggregations can be applied.



CGT Score

The Common General Test score is used as an additional performance

measure. The average CGT score can be calculated for different groups.



District Rank

District rank represents a student's ranking within the district.

Average rank can be used when comparing groups of students.



Island Rank

Island rank represents a student's overall ranking at the national

level. Average rank can be used for group-level analysis.



The main OLAP measures and their aggregations are:



Measure             Aggregation

\-----------------------------------------

Student Count       COUNT

Z-Score             AVG, MIN, MAX

CGT Score           AVG

District Rank       AVG

Island Rank         AVG



These dimensions, facts, hierarchies, and measures provide the

foundation required to populate the OLAP cube and perform

multidimensional analysis.
